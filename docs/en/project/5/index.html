LaTeXamos

22/08/2026
Node.js Express.js Docker Containerização Desenvolvimento Full-Stack Arquitetura Offline-First Comunicação Cross-Window EJS JavaScript Arquitetura Self-Hosted Persistência de Dados

O LaTeXamos é um editor de LaTeX moderno, 100% offline e portável, concebido para rodar de forma isolada dentro de um container Docker. Elimina a necessidade de configurações complexas no sistema operativo, oferecendo um ambiente completo e seguro para a edição ágil de documentos científicos.

Technologies:

Node.js, Express.js, EJS, Docker, Docker Compose, TeX Live, Multer, Adm-Zip, CodeMirror 5, PDF.js, Split.js, KaTeX, JSZip, Lucide Icons, BroadcastChannel API, CSS3, HTML5, JavaScript

Features:

  1. Edição e Compilação 100% Offline: Compilação real com TeX Live (pdflatex/latexmk) via Docker.
  2. Gestão Completa de Projetos: Criação direta, importação e exportação de estruturas .zip.
  3. Interface Redimensionável (3 Colunas): Painéis ajustáveis para navegação de ficheiros, editor de código e visualizador PDF.
  4. Editor de Código Avançado: Realce de sintaxe LaTeX (stex), fecho automático de parênteses/chavetas e temas escuros.
  5. Índice Resumo Dinâmico (Document Outline): Leitura em tempo real de \section e navegação com clique direto.
  6. Foco Inteligente de Erros: Analisador de logs do LaTeX com destaque da linha com erro no editor.
  7. Preview Destacável: Visualizador PDF em janela pop-up independente sincronizada via BroadcastChannel API.
  8. Persistência de Dados: Mapeamento de volumes Docker para preservação dos projetos na pasta ./projects_data.

Detailed Description:

O LaTeXamos é um editor de LaTeX moderno, 100% offline e portável, concebido para rodar de forma isolada dentro de um container Docker, oferecendo um ambiente seguro para edição ágil de documentos científicos.

Principais Destaques

  • Zero Configuração Local: Empacotado via Docker com compilador TeX Live integrado para compilação offline e persistência local.
  • Interface Produtiva: Layout de 3 colunas redimensionáveis (ficheiros, editor e preview) com tema escuro elegante (estilo Prism/Dracula).
  • Ferramentas Avançadas: Índice resumo dinâmico, pré-visualização PDF destacável em janela popup (sincronizada em tempo real) e foco inteligente em erros de compilação.
  • Gestão de Projetos: Importação e exportação rápida de trabalhos completos via ficheiros .zip.
