QuantumTalk

O QuantumTalk é uma plataforma de telecomunicações P2P Zero-Knowledge e altamente segura, orquestrada via Docker. Utilizando criptografia quântico-resistente (AES-256-GCM) e túneis WebRTC, garante que todo o fluxo de mensagens, áudio e vídeo seja encriptado de ponta a ponta. Com mecanismos avançados de purga de dados efêmeros, proteção contra ataques de rede e transferência segmentada de ficheiros, o sistema assegura confidencialidade absoluta e soberania total sobre os dados trocados.
