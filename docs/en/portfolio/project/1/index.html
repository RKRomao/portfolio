Freshman Support Line

11/07/2024
Web design Web development User Experience User Interface

The Freshman Support Line is a personal platform, developed with dedication and purpose, to serve as a comprehensive guide for newly arrived university students — the freshmen. The goal is simple yet impactful: to facilitate adaptation to academic life with useful information, practical tips, and personalized support.

Technologies:

HTML5, CSS3, JavaScript, Express.js, Node.js, MongoDB

Features:

  • Responsive Design: Adapted to mobile devices and desktops.
  • Category System: Clear organization of content and resources.
  • Tag Search: Quick search for specific topics.
  • FAQ System: Answers to common freshman questions.
  • GitHub Integration: Open-source repository with development history.

Detailed Description:

The Freshman Support Line is a web platform developed to help newly arrived university students adapt to academic life smoothly and easily.

Main Features

  • Initial Information: Step-by-step guide for the first days at university.
  • Academic Organization: Practical tips for managing time and studies.
  • Survival Guide: Essential tips to successfully navigate the 1st year.
  • Useful Resources: Centralized list of indispensable links and documents.
  • Interactive FAQ: Answers to the most frequent questions about university life.

The project was designed with a total focus on UX/UI, ensuring fast, intuitive, and accessible navigation on any device.
