QuantumTalk

22/08/2026

O QuantumTalk é uma plataforma de telecomunicações P2P Zero-Knowledge e altamente segura, orquestrada via Docker. Utilizando criptografia quântico-resistente (AES-256-GCM) e túneis WebRTC, garante que todo o fluxo de mensagens, áudio e vídeo seja encriptado de ponta a ponta. Com mecanismos avançados de purga de dados efêmeros, proteção contra ataques de rede e transferência segmentada de ficheiros, o sistema assegura confidencialidade absoluta e soberania total sobre os dados trocados.

Tecnologias:

Node.js, Express.js, Socket.io, WebRTC, MariaDB, Docker, Docker Compose, JavaScript (ES6+), HTML5, CSS3, Web Crypto API, AES-256-GCM, PBKDF2, Multer, Cors, Cloudflare Tunnels, TLS 1.3, Giphy API

Funcionalidades:

Comunicação P2P Encriptada: Mensagens, chamadas de voz e vídeo com encriptação de ponta a ponta (AES-256-GCM).

  • Zero-Knowledge Architecture: Chaves de encriptação derivadas no cliente (PBKDF2) sem conhecimento do servidor.
  • Purga de Dados Efêmeros: Eliminação automática de registos e ficheiros temporários.
  • Transferência de Ficheiros Segmentada: Envio seguro de anexos em chunks encriptados.
  • Notificações Push: Alertas assíncronos e em background via Web Push API.
  • Infraestrutura Self-Hosted: Orquestração completa via Docker Compose com Cloudflare Tunnels.

O QuantumTalk é uma plataforma de telecomunicações P2P Zero-Knowledge e highly segura, orquestrada via Docker. Utilizando criptografia quântico-resistente (AES-256-GCM) e túneis WebRTC, garante que todo o fluxo de mensagens, áudio e vídeo seja encriptado de ponta a ponta.

Tecnologias Utilizadas

Frontend & Interface

  • WebRTC: Túneis Peer-to-Peer (P2P) para streaming de áudio e vídeo de baixa latência.
  • Web Crypto API: Operações criptográficas executadas diretamente no browser (arquitetura Zero-Knowledge).
  • Design Mobile-First: Interface responsiva com suporte nativo a Modo Escuro e Web Push Notifications.

Backend & Lógica de Servidor

  • Node.js (Express.js): Barramento de eventos (signaling WebRTC) e API.
  • MariaDB: Persistência de ciphertext opaco e metadados criptográficos.
  • Proxy Reverso: Rotas de abstração para ocultar credenciais externas (ex: /api/giphy).

Segurança & Criptografia

  • AES-256-GCM: Cifra simétrica quântico-resistente para encriptação E2EE.
  • PBKDF2 & HMAC-SHA256: Derivação de chaves com 100.000 iterações contra ataques de força bruta.
  • SRTP & DTLS: Encriptação na camada de transporte contra ataques Man-in-the-Middle (MITM).
  • Defesa L7: Rate Limiting, proteção XSS, anti-Directory Traversal e cabeçalhos estritos (CSP, X-Frame-Options).

Infraestrutura & DevOps

  • Docker & Docker Compose: Containerização e orquestração de serviços com gestão segura de ambiente.
  • Cloudflare Tunnels & TLS 1.3 Strict: Encapsulamento de rede prevenindo Packet Sniffing com Perfect Forward Secrecy.
