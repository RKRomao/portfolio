Linha de Apoio ao Caloiro

11/07/2024

A Linha de Apoio ao Caloiro é uma plataforma pessoal, desenvolvida com dedicação e propósito, para servir como um guia completo para estudantes universitários recém-chegados — os famosos caloiros. O objetivo é simples mas impactante: facilitar a adaptação à vida académica com informação útil, dicas práticas e suporte personalizado.

Tecnologias:

HTML5, CSS3, JavaScript, Express.js, Node.js, MongoDB

Funcionalidades:

  • Design Responsivo: Adaptado a dispositivos móveis e desktops.
  • Sistema de Categorias: Organização clara de conteúdos e recursos.
  • Busca por Tags: Pesquisa rápida de tópicos específicos.
  • Sistema de FAQ: Resposta a perguntas frequentes de novos alunos.
  • Integração GitHub: Repositório open-source com histórico de desenvolvimento.

Descrição Detalhada:

A Linha de Apoio ao Caloiro é uma plataforma web desenvolvida para ajudar estudantes universitários recém-chegados a adaptarem-se à vida académica com tranquilidade e facilidade.

Funcionalidades Principais

  • Informações Iniciais: Guia passo a passo para os primeiros dias na universidade.
  • Organização Académica: Dicas práticas para gerir o tempo e os estudos.
  • Guia de Sobrevivência: Dicas essenciais para superar o 1º ano com sucesso.
  • Recursos Úteis: Lista centralizada de links e documentos indispensáveis.
  • FAQ Interativo: Respostas às dúvidas mais frequentes da vida universitária.

O projeto foi concebido com foco total em UX/UI, garantindo uma navegação rápida, intuitiva e acessível em qualquer dispositivo.
